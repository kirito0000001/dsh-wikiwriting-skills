# 文体骨架：剧本（影视 / 游戏）

> 本文归属的规则：`WSC-nn` ｜ 来源与许可见文末
> **消费约定（接 `03_接口_v0.5` §9）**：本骨架只规定「这一段该怎么写」。写什么由 `01_素材账本.md` 决定 —— `一手已核` 可直接写，`自测` 必须带测量条件，`二手线索` 必须标注或先核实，`待复审` 交付前重核并标「截至 YYYY-MM-DD」，`已推翻` 永久禁用。设定/数值（人物年龄、场号、地点名、时间线）一律过 `02_设定表.md` 的引用路径取，不在正文里另立一份。
> **级别词汇**：`structural_invariant`（脚本可阻断）／`reviewed_invariant`（reviewer 引证据判）／`craft_default`（作者说明理由即可覆盖）／`taste_option`（不得单独阻断）。词汇借自 MIT 的 `zenstory-ai/drama-skills`，条文为本工作区自写，逐条见 §5。
> **每条规范自带四字段**（接 §9）：`〔源｜依据类型｜版本与实施日期｜适用文体〕`。

## 0. 适用与不适用

**适用**：
- 电影 / 电视（含网络剧、竖屏短剧）剧本的**正文格式与结构骨架**；
- 舞台剧的**部分**（场景标题、角色表、对白块 —— 幕/场切分与舞台指示按各自剧种惯例）；
- 游戏**分支对白脚本**的机器可读结构（节点、选项、汇合、跳转）。

**不适用**（跨了就是文体越界，见接口 §9）：
- **成片层规范**：字幕区、母版、片头字幕 —— 走 `GY/T 357-2024`，不是写作规范；
- **送审与备案**：剧本梗概备案、微短剧分类分层审核 —— 内容合规另立，不进格式骨架；
- **分镜 / 镜头表 / 生成参数**：镜号、景别、运镜、焦段、素材位**不得写进剧本正文**，那是下游所有权；
- **小说化叙事**：人物心理、前史、"他心想" 不进动作行（`WSC-R01`）；
- **中外格式互套**：中英两套的**页数、字体、对白体例不互通**（`WSC-R12`）—— 英文页数上限不能直接套中文稿；
- **游戏的任务设计、关卡、数值**：本骨架只管"分支对白脚本长什么样"。

**先判用途再判格式**（`WSC-R12`）：同一份内容给导演拍、给平台评、给工会注册，格式要求不同。判断顺序是**收件人 → 媒介 → 格式**，不是先挑格式。

## 1. 结构骨架

剧本 = **一串场景**；每个场景 = **场景标题 + 动作 + 对白块**。所有元素都在这个层级里，没有第五种。

| 元素 | 英文惯例名 | 形态 | 判定式（可机检的部分） |
| --- | --- | --- | --- |
| **场景标题** | Scene Heading / Slugline | `EXT. BRICK'S POOL - DAY`／`内景 阿強家客廳 夜` | 行首命中 `INT/EXT/EST/INT./EXT/INT/EXT/I/E` + 「.」或空格；或行首「.」+ 字母数字强制（输出去掉该点）。**三要素齐备**：空间性质 + 地点 + 时间 |
| **动作 / 场景描写** | Action / Scene Description | 现在时，只写镜头拍得到的；一段 4–5 行 | 场景标题后**紧跟至少一行动作**；段落行数可数 |
| **角色名** | Character Cue | `CHARACTER #1`／`阿強` | 整行大写 + 前有空行 + 后无空行 + 至少一个字母字符；`@` 可强制（小写名/非拉丁文） |
| **对白** | Dialogue | 紧跟角色名或括注 | 对白**不得独立出现**，必须前接角色名 |
| **括注** | Parenthetical / Wrylie | 整行 `(pause)` / `（不让门外的人听见）` | 整行、圆括号包裹、位于角色名或对白之后 |
| **转场** | Transition | `CUT TO:` / `>Burn to White.` | 整行大写 + 前后空行 + 以 `TO:` 结尾；`>` 可强制 |
| **双人对白** | Dual Dialogue | 第二角色名行以 `^` **行尾**结束 | caret 必须是该行最后一个字符 |
| **幕 / 集标签** | Teaser / Act / Tag | `TEASER`／`ACT ONE`／`END OF ACT ONE` | 与 `END OF …` **成对**；每幕起新页，以 `FADE IN:` + 场景标题开头 |
| **游戏节点** | knot（ink）／node（Yarn） | `=== top_knot ===`／`title: Start` + `---` … `===` | 节点 = 一个头部 + 一个正文；正文 ≥ 1 条语句 |
| **游戏选项与汇合** | choice / gather（ink）；option（Yarn） | `* [开门] -> paragraph_2`；`- 汇合点` | 缩进/星号层级必须闭合；流不得出现 loose end |

**中文变体（同一官方範例内就有两式，都不是错）**：
- **参考一**：`阿強：妳這什麼態度？` —— 人名与台词**同行**，用全角冒号；
- **参考二**：`阿強` 单独一行，台词**下一行**。
- 动态描写的符号：106 年度格式用 `△` 置左、次行与首行 `△` 齐头；第 48 届範例的参考一**未印** `△`。→ 是否用符号看目标格式版本，**同一项目内必须恒一致**（`WSC-S20`）。

**游戏分支的三条结构事实**（与影视不同，必须显式写）：
1. **人写的是图，不是线**：节点之间的连接必须显式（跳转/选项/汇合），不能靠"读者自己往下读"；
2. **汇合点必须显式**：多条分支回到同一条线，要用 gather 之类的记号写出来，否则每条分支都得各自命名；
3. **流必须终结**：每个入口都要能走到 `-> END` / `-> DONE` / 选项或跳转，编译器会报 loose end。

## 2. 规则表

### 2.1 `structural_invariant`（脚本可阻断）

| ID | Class | Knowledge |
| --- | --- | --- |
| `WSC-S01` | structural_invariant | 条件：英文稿写场景标题行。要求：行首命中 `INT`／`EXT`／`EST`／`INT./EXT`／`INT/EXT`／`I/E` 之一，且其后紧接「.」或空格；判定**大小写不敏感**。例外：行首单点 `+` 字母数字可强制为场景标题（输出时去掉该点），借此让「…」开头的动作行不被误判。行首为 `!` 时强制为动作。 〔S1｜官方规范｜Fountain 1.1（2014-03）｜英文剧本〕 |
| `WSC-S02` | structural_invariant | 条件：任何场景标题。要求：**空间性质（内/外/内外）+ 地点 + 时间（日/夜/晨/昏）三要素齐备**。例外：旧稿整槽缺失时**留空该槽，不得按上下文补** —— 补出来的时段会直接变成整场的布光依据。 〔S2、S3｜广播机构模板 + 政府规范｜BBC 2004-02-06／106 年度（2017）｜中英剧本〕 |
| `WSC-S03` | structural_invariant | 条件：写完一个场景标题。要求：**紧随至少一行动作**，且标题不得落在页底成为孤行（标题与动作不得被分页拆散）。 〔S2、S5｜广播机构模板｜2004-02-06／TV 版同年｜影视剧本〕 |
| `WSC-S04` | structural_invariant | 条件：写角色名行。要求：整行大写、前有一空行、后无空行，且**至少含一个字母字符**（`R2D2` 可以，`23` 不行）。例外：`@` 前缀可强制为角色名并保留大小写混写（小写名、非拉丁文姓名）。 〔S1｜官方规范｜Fountain 1.1｜英文剧本〕 |
| `WSC-S05` | structural_invariant | 条件：任何对白。要求：**必须前接角色名或该角色名下的括注**；对白不得裸行出现。 〔S2｜广播机构模板｜2004-02-06｜影视剧本〕 |
| `WSC-S06` | structural_invariant | 条件：写括注。要求：整行、圆括号包裹、位于角色名或对白之后。例外：1.1 起**不再要求**括注大写（1.0 曾要求）。 〔S1、S2｜官方规范 + 模板｜Fountain 1.1／2004｜影视剧本〕 |
| `WSC-S07` | structural_invariant | 条件：写转场。要求：整行大写、前有且后有空格行、**以 `TO:` 结尾**；`>` 前缀可强制。例外：冒号后加一个空格即退化为动作行（Fountain 的显式逃逸口）。 〔S1｜官方规范｜Fountain 1.1｜英文剧本〕 |
| `WSC-S08` | structural_invariant | 条件：写双人（同时）对白。要求：第二个角色名行以 `^` 结束，**caret 必须是该行最后一个字符**（名字与 caret 之间的空格被忽略）。 〔S1｜官方规范｜Fountain 1.1｜英文剧本〕 |
| `WSC-S09` | structural_invariant | 条件：写剧集稿的幕/集结构。要求：`TEASER`／`ACT n` 与 `END OF TEASER`／`END OF ACT n` **成对出现**；每幕从**新页**开始，且以 `FADE IN:` 后接场景标题开头；全剧以 `FADE OUT.` + 居中 `THE END` 收尾。例外：幕内两场之间要表示淡出淡入，用 `FADE TO:`，不用 `FADE OUT.`。 〔S5｜广播机构模板｜TV 版 2004｜剧集剧本〕 |
| `WSC-S10` | structural_invariant | 条件：定页码。要求：**第 1 页 = 正文第 1 页**（第一场或 Teaser），标题页不计入。 〔S2、S5｜广播机构模板｜2004｜影视剧本〕 |
| `WSC-S11` | structural_invariant | 条件：**英文 spec 稿（投稿稿）**。要求：**不出现场景编号** —— 编号只属于拍摄稿。<br>⛔ **原句自相矛盾**：旧版把「需要编号时用 `#…#` 包裹」和「不出现场景编号」写在同一句里，**在同一份 spec 稿上给出相反结论**。已拆开：`#…#` 是**拍摄稿**的合法编号形态（内容限字母数字加连字符与点），**spec 稿一律不得编号**。<br>⛔ **必须与 `WSC-S17` 一起看**：S17 要**中文大陆格式**的场号用「阿拉伯数字＋顿号」。两条字面不矛盾（一英一中），但**「本稿走哪一套」在本文件里没有定义** → **门禁一旦错路由，必出 100% 误报**。见 `WSC-S17` 的作用域条款。 〔S2、S1｜模板 + 官方规范｜2004／Fountain 1.1｜英文剧本〕 |
| `WSC-S12` | structural_invariant | 条件：对外投稿。要求：**完全匿名** —— 不得出现姓名、笔名、经纪人名或任何可识别记号。例外/坑：部分编剧软件导出 PDF 时**自动生成标题页并写入姓名**，必须在导出后人工确认删除；即使无意为之也算不合格。 〔S6、S3｜广播机构投稿规范 + 政府徵件规定｜BBC 现行／106 年度｜中英剧本〕 |
| `WSC-S13` | structural_invariant | 条件：投稿前核页数。要求：**BBC 投稿：30–130 页，且页数只算对白页，不含标题页、角色表与前后附页**；低于 30 或高于 130 即判定不合格。**台湾徵件：50–100 页（整本）**。例外：两套制度口径不同，**不得互换**，按收件方的须知逐条适用。 〔S6、S3｜广播机构规范 + 政府规定｜BBC 现行／106 年度｜中英剧本〕 |
| `WSC-S14` | structural_invariant | 条件：定稿件版面。要求：**英文：Courier 12pt**，标准页边距（不得用超宽边距虚增页数），不加改变标准排版惯例的页眉页脚。**中文（台湾徵件）：直式横书繁体、12 级字、行高 16pt 为宜、页码置页尾居中、双面、左侧装订**。 〔S6、S3｜广播机构规范 + 政府规定｜BBC 现行／106 年度｜中英剧本〕 |
| `WSC-S15` | structural_invariant | 条件：排版分页。要求：**禁止「一景一页」** —— 不得为每场戏新起一页；场景须连续流下，同一页上可以接着下一场。 〔S6｜广播机构规范｜BBC 现行｜影视剧本〕 |
| `WSC-S16` | structural_invariant | 条件：一段对白要跨页。要求：**上页至少留两行**，且**只能断在一个句子之后**；续页以 `CHARACTER (CONT'D)` 开头。括注**不得**留在页底，必须移到次页角色名下的第一行。 〔S2、S5｜广播机构模板｜2004｜影视剧本〕 |
| `WSC-S17` | structural_invariant | 条件：**大陆通行格式**的中文稿写场标与正文。要求：**场号用阿拉伯数字 + 顿号**（`1、`）、场标**顶格**；正文每段**首行缩进两字符**、不得顶格；对话人姓名 + 冒号、每次对话另起一段。<br>⛔ **辖区必须显式声明，不许猜**：台湾徵件格式的场标是 `1. 內景　阿強家客廳　夜`（**半角点**，§3 例 1 标为 ✅）—— **拿本条检台湾格式稿会 100% 误报**。所以本条**只在稿子已声明为大陆通行格式时适用**。这就是 `WSC-S11`↔`WSC-S17` 那条冲突的解：**「本稿走哪一套」（语种 × 辖区 × spec/拍摄）必须是显式字段。**<br>⚠️ **「加粗」那一半已删** —— 纯文本里没有加粗记号，判它必须读 `.docx` 的 `w:b`（属产物层，见 `WSC-S14` 的处置）。 〔S7｜从业者规范（国内通行格式）｜2019 前后｜中文剧本〕 |
| `WSC-S18` | structural_invariant | 条件：中文稿写动作（旁白/动作）段。要求：动作与旁白**另起一段即可、不加标注**；且**动作段不得以「短语 + 全角冒号」开头** —— 那与 `角色名：台词` 字面同形，索引器只能报歧义交人判。改法：把行首冒号换成破折号、逗号或一个动词（句中的冒号不受影响）。 〔S7、S4｜从业者规范 + MIT 参考实现｜2019 前后／c2426e0（2026-10-03）｜中文剧本〕 |
| `WSC-S19` | structural_invariant | 条件：项目使用生产标签。要求：标签必须**成对闭合、语法可解析、不得互相冒充**（`[VO]` `[OS]` `[SFX]` `[画面文字]` `[连续性]` `[转场]`）。校验器只证明"已写的标签合法"。 〔S4｜MIT 参考实现｜c2426e0（2026-10-03）｜中文短剧 / 生产稿〕 |
| `WSC-S20` | structural_invariant | 条件：采用符号体系（`△` 环境与空镜／`▲` 人物动作，或旧稿的单一符号）。要求：**同一稿内不得混用两套符号体系** —— 出现第三种符号即报，因为那说明项目内没有统一。<br>⛔ **原句「符号分工恒一致」已收窄（v0.5 裁决）** —— 判它要逐行判断「这行写的是环境还是人物」，而**规则原文自己就写了「按内容判断」**：那是语义判断，**归 `WSC-R` 级**（要人判）。脚本能确定性判的只有"出现了哪些符号、在第几行"。<br>⚠️ **同一内容横跨三级，各管一段（这就是它原本重复的原因）**：`WSC-C10`（`craft_default`）= 用哪套符号的**默认值**；`WSC-T03`（`taste_option`）= **私有符号的自由度**；**本条 = 不得混用**。 〔S4、S3｜MIT 参考实现 + 政府规范｜c2426e0／106 年度｜中文剧本〕 |
| `WSC-S21` | structural_invariant | 条件：给场景编号。要求：**场景 ID 在同一项目内唯一且稳定**；修改显示名不改 ID，真正新建场景才分配新 ID；拆分/合并后无法明确映射时**展示映射选择，不得静默猜测**。 〔S4｜MIT 参考实现｜c2426e0｜中文短剧〕 |
| `WSC-S22` | structural_invariant | 条件：Yarn 分支脚本。要求：节点 = **一个头部 + 一个正文，顺序固定**；头部以 `---` 结束、正文以 `===` 结束；**必须含 `title` 标签且文件内唯一**（重复即报错）；正文**至少一条语句**（对白 / 命令 / 选项）；文件用 UTF-8 且不带 BOM。 〔S9｜官方规范｜Yarn Spec（dd8d9b4，2026-09-16）｜游戏对白脚本〕 |
| `WSC-S23` | structural_invariant | 条件：ink 分支脚本。要求：knot 以 `=== 名 ===` 声明（名不得含空格）；选项行以 `*` 开头、嵌套用 `**`；汇合点以 `-` 开头；**流程不得出现 loose end** —— 每个入口都要能走到 `-> END`、`-> DONE`、选项或跳转，否则编译期与运行期都会告警。 〔S10｜官方文档｜Writing with ink（35c63e5，2026-05-05）｜游戏对白脚本〕 |
| `WSC-S24` | structural_invariant | 条件：同一份稿同时含集/幕/场三级标题。要求：三层标签**不得互相冒充**（`TEASER` 与场景标题不得写在同一行；`ACT` 标签不承担场景标题的三要素）。 〔S5｜广播机构模板｜TV 版 2004｜剧集剧本〕 |

### 2.2 `reviewed_invariant`（reviewer 引证据判）

| ID | Class | Knowledge |
| --- | --- | --- |
| `WSC-R01` | reviewed_invariant | 条件：写动作行。要求：只写**屏幕上正在发生的事**，**不得**滑进人物心理、前史或小说化叙述。判据：删掉这一行，是否丢掉一个**可拍摄画面**（丢的只是形容词 → 删对了；丢的是画面 → 这行写对了）。例外：需要让观众听到内心时，用 `OS`/`VO` 或屏显文字显式选通道，不靠动作行夹带。 〔S2、S4｜广播机构模板 + MIT 参考实现｜2004／c2426e0｜影视与短剧剧本〕 |
| `WSC-R02` | reviewed_invariant | 条件：写 spec / 投稿稿。要求：**不写相机与技术指示**（`CLOSE-UP`、`PAN TO`、`TRACKING SHOT`、`we see`、`the camera…`）；这些属于拍摄稿。例外：确实是拍摄稿或已获授权的场合，允许精确技术指示与场景编号。 〔S2、S5｜广播机构模板｜2004｜影视剧本〕 |
| `WSC-R03` | reviewed_invariant | 条件：审每一场。要求：场景要有**议程、反对、转向与退出**且角色可表演；一条关键心理/认知变化必须有**可表演载体**（行为、证据、空间后果或有意选择的声音）。 〔S4｜MIT 参考实现｜c2426e0｜中文短剧〕 |
| `WSC-R04` | reviewed_invariant | 条件：审对白。要求：对白质量由**议程、关系、潜台词与它造成的变化**判断，**不得由长度或比例判断**。 〔S4｜MIT 参考实现｜c2426e0｜中文短剧〕 |
| `WSC-R05` | reviewed_invariant | 条件：审一集的完整性。要求：把"必读屏显文字、`VO`/`OS`、改变行动或信息的关键声音、有叙事意义的转场、易丢的连续性事实（如道具交接）"逐项对照剧情意义查，**缺失即 flag**。这是语义判断，不能由关键词扫描代替。 〔S4｜MIT 参考实现｜c2426e0｜中文短剧〕 |
| `WSC-R06` | reviewed_invariant | 条件：拿到旧稿/外来稿。要求：**先按槽位识别、再对应，格式差异本身不是缺陷** —— 不得因为来稿不合某一套规范格式就判它有问题；某槽位整槽缺失时留空而**不得补**。 〔S4｜MIT 参考实现（定性案例阅读）｜c2426e0｜中文剧本〕 |
| `WSC-R07` | reviewed_invariant | 条件：用"一页≈一分钟"估时长。要求：**只在总量上做粗算**，且必须带上偏差范围与适用条件（三口径见 §3 争议一）；用它**反向逼编剧掐页数**属误用。 〔S11、S12、S13｜独立实证研究 + 编剧本人 + 厂商口径｜Follows 2026-03-30／August 2020-03-09／Final Draft 现行｜影视剧本〕 |
| `WSC-R08` | reviewed_invariant | 条件：估体量。要求：90 分钟电影剧本一般 **90–120 场**；一集 45 分钟剧 **25–35 场**；**分场阶段**把 30–50 个情节点扩到 **100–120 个场景**（此数指分场稿，不是成稿场景数）。例外：以上都是"一般情况"，来源本身不称其为标准。 〔S14、S7｜高校 MOOC 教材 + 从业者规范｜超星 200016241／2019 前后｜中文影视剧本〕 |
| `WSC-R09` | reviewed_invariant | 条件：把英文页数门槛套到中文稿。要求：**不成立** —— 中英字体、字号、字长不同，英文剧本规定的字数**不对应中文字数的体量**；且中文读者的阅读习惯与好莱坞格式不合。中文稿的体量用**场数 + 字数**估，不直接套页数。 〔S7｜从业者规范（国内通行格式）｜2019 前后｜中文剧本〕 |
| `WSC-R10` | reviewed_invariant | 条件：切分场景。要求：场景是**空间 + 时间**双重概念 —— 同一空间的日夜景算两场，门外与门内算两场；且**场景名在整个剧本中唯一**（前文用过"卧室"，之后再写"卧室"就表示同一间）。 〔S14、S7｜高校教材 + 从业者规范｜超星／2019 前后｜中文剧本〕 |
| `WSC-R11` | reviewed_invariant | 条件：把旧稿规范化（改字段、改标点、改格式）。要求：**改变说话者、行动先后、事实、因果、态度或未说内容都算语义变化**，即使句子看起来只被"整理"；**台词逐字保留**；未识别的标记原样保留并告警。例外：接受规范化**前**不得把预览当权威源，取消即不改变原稿。 〔S4｜MIT 参考实现｜c2426e0｜中文剧本〕 |
| `WSC-R12` | reviewed_invariant | 条件：同一内容要交付给不同收件人（导演/平台/评奖/工会注册）。要求：**格式不得跨文体、跨媒介、跨地区照搬** —— 期刊规则不当论文规则用那类错误在这里同样成立；按收件方的须知逐条适用。 〔S6、S3、S2｜机构规范｜现行｜影视剧本〕 |
| `WSC-R13` | reviewed_invariant | 条件：审游戏分支脚本的可玩性。要求：选项必须造成**可辨的议程或策略变化**，汇合后应能继续；重复同质的分支只是"换了个人名"时应合并。判据：把这批选项并成一个默认选项，剧情损失了什么。 〔S4、S10｜MIT 参考实现 + 官方文档｜c2426e0／ink 35c63e5｜游戏剧本〕 |

## 3. 正反例（成对，各带出处）

**例 1 · 场景标题三要素**
- ❌ `客厅 晚上` —— 缺内外景、缺规范时间词 〔判据 S3/S7〕
- ✅ `1. 內景　阿強家客廳　夜` 〔台湾文化部 106 年度格式〕；英文侧：`EXT. BRICK'S POOL - DAY` 〔Fountain 规范示例〕

**例 2 · 动作行只写可拍的**
- ❌ 「他心想，她一定恨他。」—— 屏幕拍不到 〔BBC 电影模板明禁"superfluous novelistic text related to character thoughts or back-story"〕
- ✅ 「王怀安瞳孔收缩，额头渗出汗珠。」〔`drama-skills` 范例 A，MIT〕—— 同一情绪换成可见证据

**例 3 · 相机指示**
- ❌ `CLOSE-UP on the brass key.` 写在 spec 稿里 〔BBC：相机与技术指示只属拍摄稿〕
- ✅ 把镜头意图写成动作与物件：「他捏住黄铜钥匙，指节发白。」

**例 4 · 括注**
- ❌ `（非常愤怒地大声吼叫）` —— 堆叠同义情绪词，不可执行 〔`drama-skills` §3.2 要求"提示描述一个可执行策略或变化，不堆叠同义情绪词"〕
- ✅ `（不让门外的人听见）` 〔同上示例〕—— 一条可执行的策略

**例 5 · 对白不能裸行**
- ❌ 空一行后直接写一句台词 〔BBC：「Dialogue must always be preceded by a character name and never appear on its own.」〕
- ✅ `CHARACTER #1` 换行接台词

**例 6 · 一景一页**
- ❌ 每场戏都新起一页 〔BBC 投稿规范明禁 "scene-per-page" formatting〕
- ✅ 场景连续流下，同页可接下一场

**例 7 · 中文动作段的行首冒号**
- ❌ `第二格：一只手把杯子推过去。` 〔与 `角色名：台词` 同形，索引器只能报 `ambiguous_dialogue_or_action`〕
- ✅ `第二格换成一只手把杯子推过去。` 〔`drama-skills` §3.1 给出的改法〕

**例 8 · 游戏分支的流终止**
- ❌ `=== top_knot ===` 写完正文没有任何跳转或结束 → 编译期告警 `Apparent loose end exists where the flow runs out` 〔ink 官方文档〕
- ✅ 结尾补 `-> END`

**例 9 · Yarn 节点完整性**
- ❌ 复制一个节点忘了改 `title:`（同文件内重复）→ 规范要求**报错** 〔Yarn Spec：标题在文件内必须唯一〕
- ✅ 每个节点一个唯一 `title`，头部以 `---` 收、正文以 `===` 收

**例 10 · 双人对白的 caret**
- ❌ `STEEL ^  Screw retirement.`（caret 不在行尾）
- ✅ `STEEL ^` 独占角色名行末 〔Fountain 规范：caret 必须是行末字符〕

### 争议一：「一页 ≈ 一分钟」三种口径（**不选边，各记适用条件**）

| 口径 | 代表说法 | 适用条件 |
| --- | --- | --- |
| **行业惯例派** | 100 页的规范剧本通常对应 **95–110 分钟**成片；甜区 **90–115 页**；明说"不是字面意思""是估算" 〔Final Draft〕 | 粗估预算、排期、选片长区间时可用 |
| **数据实证派** | 2,520 部美国 Letter 剧本 + 351 部 A4 剧本：页/分比平均 **1.1**，**1 页 ≈ 55 秒**（扣掉片尾字幕约 54 秒）；**只有 18.2%** 的剧本落在 0.95–1.05；喜剧 1.15、音乐剧 0.90；A4 为 1.02 而 Letter 为 1.1。2026 年修正版规则：**约一分钟，±20%** 〔Stephen Follows, 2026-03-30〕 | 需要给区间和偏差时用；跨纸张尺寸换算（A4 页数 ×≈1.07 ≈ "好莱坞页"） |
| **编剧本人派** | 「这条经验法则经不起细看」；总页数与总时长**只有总量相关**，对单个项目**几乎没有预测力**；真正的做法是**场记逐场做 script timing**；页数上限是合同与行业惯性，为它掐页是白工 〔John August, 2020-03-09〕 | 用它**要求编剧删页**时，此派明确反对 |

**共同点（三方都不否认）**：120 页 ↔ 约 2 小时这个量级的粗对应成立。**分歧点**：这个数能不能当约束用。

### 争议二：场景标题要不要全大写

- **模板派**：广播机构模板写"Scene headings are typed in capitals" 〔BBC 电影模板〕；中文侧政府格式要求「場景標題格式（**粗體**）」 〔台湾文化部 106 年度〕。
- **规范派**：Fountain 规范说大写**"recommended to increase readability, it is not required"**，并明示例外 `ext. brick's pool - day` 仍会被识别为场景标题 〔fountain.io〕。
- **合并口径**：**机器可解析性不依赖大小写**（`WSC-S01` 判大小写不敏感）；**人对人的投稿与模板场合按全大写**（`WSC-C01`）。

### 争议三：中国大陆有没有统一剧本格式

- **否定证据（两条）**：高校 MOOC 教材直言「剧本写作**没有非常标准的统一格式**」，只给一般性的场景数区间 〔超星〕；从业者规范开篇即说所讲的是「国内影视行业当中通行的剧本格式……**并不等同于好莱坞通行的剧本格式**」 〔66rpg〕。
- **肯定证据（一条，限台湾）**：台湾文化部影视局**有**政府徵件用的《劇本內文寫作參考格式》，且带硬规格（50–100 页、12 级字、行高 16pt、不得署名），并预告"自 107 年度起一律使用本写作格式" 〔文化部 PDF〕。
- **结论**：**"有官方格式"与"没有官方格式"两个陈述都对，取决于辖区**。中国大陆侧本轮**未取得任何官方剧本写作格式文件**（监管文件只到成片母版与内容审核层）—— 这是本骨架的已知空缺，不是"中国没有规范"的证明。

## 4. 常见失败模式

| # | 失败模式 | 触发它的规则 | 典型症状 |
| --- | --- | --- | --- |
| 1 | **一景一页 / 页数虚增** | `WSC-S15`、`WSC-S14` | 每场新起页、超宽页边距、加页眉页脚把 60 页撑成 100 页 |
| 2 | **在 spec 稿里当导演** | `WSC-R02` | 满篇 `CLOSE-UP`、`we see`、`the camera pans` |
| 3 | **把小说当剧本** | `WSC-R01` | 「他回想起十年前……」「她心里一阵酸楚」；不可拍 |
| 4 | **括注当情绪垃圾桶** | `WSC-C04` | `（愤怒地）（大声地）（激动地）` 三连 |
| 5 | **对白裸行 / 角色名不规范** | `WSC-S05`、`WSC-S04` | 台词没有角色名；角色名大小写混写导致同一人被当成两人 |
| 6 | **场景标题缺要素或落在页底** | `WSC-S02`、`WSC-S03` | `外景 街道`（无日夜）；标题孤零零挂在页尾，动作翻到次页 |
| 7 | **格式跨区照搬** | `WSC-R12`、`WSC-R09` | 拿 BBC 的 30–130 页（对白页）去卡中文整本稿；拿台湾 50–100 页去卡英文 spec |
| 8 | **分场阶段就写台词** | `WSC-C11` | 分场稿里全是完整对白，改结构时台词全废 |
| 9 | **动作段与对白撞形** | `WSC-S18` | 动作行以「第二格：」开头，索引/校对工具报歧义 |
| 10 | **符号体系混用** | `WSC-S20` | 同一稿里 `△` 既写环境又写人物，下游分不清哪行是可拍动作 |
| 11 | **游戏分支 loose end** | `WSC-S23` | 有节点没有任何出口；改稿后旧跳转指向已改名节点 |
| 12 | **游戏选项无差异** | `WSC-R13` | 三个选项通向三段只换了人名的同一段剧情 |
| 13 | **旧稿规范化时"顺手润色"** | `WSC-R11` | 把台词「你走吧」改成「你还是走吧」，语义已变而无人记录 |
| 14 | **投稿没做匿名** | `WSC-S12` | 编剧软件自动生成的标题页带着作者名——直接判不合格 |
